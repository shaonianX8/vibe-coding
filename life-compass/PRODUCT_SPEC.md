# 产品规格与验收

## 使命

在有限的时间、金钱、健康和精力约束下，帮助用户持续识别当前最重要的事，降低正确行动的启动成本，从真实结果中学习，逐步建立经济自由、能力、作品、健康和可信赖的关系。

它的目标不是让任务做得更多、工作时间更长，而是让长期生活更自主、更可持续。

## 五条最高约束

1. 不能用增加记录来代替改善行动。
2. 不能用复杂分析来代替解决现实问题。
3. 不能用短期反馈来代替长期价值。
4. 不能用过去的个人特征永久定义未来的人。
5. 维护这个工具的成本不能超过它创造的价值。

## 七条设计原则在代码里的落点

| 原则 | 落点 |
| --- | --- |
| 人生是有限资源配置 | 每天只突出两件事：一件现实责任，一件长期积累 |
| 长期目标和短期约束并存 | 正常、紧急、恢复三种模式；紧急和恢复模式下长期积累可选，但紧急模式持续 14 天会预警 |
| 行动比计划复杂度重要 | 结果记录区分 思考、计划、准备、执行、完成交付、获得结果；只有标记为原创且达到交付级的才算作品 |
| 通过改变条件解决行为问题 | 未开始时先选障碍（7 类），系统据此调整下一次任务的条件，而不是催促 |
| 个人特征是可修正假设 | 假设单独存放，标明来源，可被标记为不再成立；AI 推测只能写成假设 |
| 目标可变，原则相对稳定 | 战略版本化，修改必须写原因，可以恢复；AI 提案在数据库层面就无法生效 |
| 软件本身也要接受检验 | 从第一天记录计划耗时、记录耗时、提醒被点开率，作为基线 |

## V0 已实现的功能

**今天页**
- 显示当前阶段、模式、可跳过的精力与身体状态
- 自动预填两件关键任务：优先继承最近未完成的任务（7 天内），否则使用当前季度重点
- 每件任务包含：做什么、第一个动作、几点开始、在哪里、完整目标、最低行动、截止日期（现实责任）、是否原创作品
- 一键确认计划；开始行动；记录结果（5 种状态、产出阶段、障碍、备注，支持键盘语音输入）
- 记录后给出下一步：继承剩余部分、缩小任务、换时间、写清第一步、引入外部承诺、只做最低行动、重新评估目标
- 连续 3 次未开始进入障碍分析，并优先推荐历史上真正奏效过的调整方法
- 建议可以修改后采纳，或拒绝；可选让 AI 细化
- 模式建议（只建议，不切换）

**记录页**
- 规则预警：原创交付停滞、连续未开始、紧急模式过长、精力持续偏低；每条带事实、证据、可能解释、未知、最小调整、复查日期，可标注不准确
- 最近 7 天小结、每日记录、近两周障碍、补记过去 7 天未记录的任务
- 工具自检：计划耗时、记录耗时、提醒被点开次数

**方向页**
- 人生终局、价值原则、2036 战略、研究主题、必要条件、当前阶段、季度重点、主要限制因素
- 战略修改（新版本、必须写原因）、历史版本与恢复
- 事实、假设与约束：带来源、复查日，过期提示待确认
- 提醒时间、时区、开关、暂停；本设备通知开启、关闭、测试
- 数据导出、删除本人全部数据、部署助手、退出登录

**后台**
- 云端定时提醒：Supabase Cron 每 10 分钟调用，每天最多一条主提醒，已确认计划不发，失败有限重试，并发和重复调用不重复发送
- 推送服务接收不等于用户收到；只有点开通知才记为已打开

## 后续版本（只列方向，不提前实现）

- **V1**：经济记录与现金流规则预警；完整周复盘（上一个完整自然周）；专项健康计划导入（120 天训练计划，保留来源、版本、有效期，到期提醒确认）；结构化 AI 周分析；自由文本结构化提取（可更正）。
- **V2**：月、季度、年度复盘；五种资本趋势；必要条件状态评估（未建立、萌芽、稳定、可扩展，附证据）；重大决策记录与复盘；调整效果评估。
- **V3**：按实际需要再考虑日历、财务、健康数据接入。

每四周用「工具自检」复查一次：如果记录负担上升而关键行动没有改善，优先删减功能，而不是增加功能。
