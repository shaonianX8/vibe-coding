# 长期战略初始资料

这份文件是初始战略的公开部分，对应应用里的初始模板（`src/lib/strategy/template.ts`）。

**它刻意不包含任何个人敏感背景**：教育与工作经历、收入、债务、医疗、家庭与关系、具体客户和合作方名称。这些信息只应该写进应用里的「方向 → 事实、假设与约束」，存放在你自己的受保护数据库中。

首次登录时，模板会写入数据库并标记为「来自模板，待确认」。之后的修改都在应用内完成，并保存为新版本。这份文件不会随你的修改自动更新，以应用内的当前版本为准。

## 人生终局

成为一个能够独立思考、持续学习、创造真实价值、维护健康和重要关系，并拥有较大生活自主权的人。拥有自己的作品、长期研究主题、真实读者和可信赖的职业声誉。

不为名气、财富和社会认可，持续牺牲健康、诚信、亲密关系和现实责任。

## 价值原则（相对稳定）

长期健康、诚信、尊重他人、持续学习、经济自主、真实关系、创造价值。

具体职业目标、内容方向和商业模式可以随世界变化调整；这些原则的稳定性更高。重大战略变化需要用户确认。

## 2026 至 2036 年十年战略

从依赖单一客户和个人劳动时间的写作者，成长为拥有稳定收入结构、原创作品、专业判断、长期读者和可持续商业模式的作者型创作者。

### 长期研究主题

人在科技和社会快速变化的时代，如何保持独立思考、持续学习、行动能力以及生活自主权。

重点领域：AI 与人类认知；科技、经济和社会结构变化；个人成长、职业发展与现实决策；跨学科思考和证据判断。它们应构成相互关联的研究体系，允许根据研究和读者需求调整。

## 五种人生资本

| 资本 | 内容 |
| --- | --- |
| 经济资本 | 收入、储备、资产、风险承受能力和选择自由 |
| 能力资本 | 知识、研究、判断、表达与经营能力 |
| 作品资本 | 原创内容、长期研究、个人信誉和读者关系 |
| 健康资本 | 身体功能、睡眠、运动恢复与长期健康 |
| 社会资本 | 亲密关系、家庭责任、朋友、合作网络、信任与互惠 |

五种资本不加权成一个人生总分。健康、安全、经济底线和重要关系责任是约束条件，不能被高收入抵消。好比一张桌子的几条腿，某条腿太短时，其他腿再长也放不稳东西。

## 通向长期目标的必要条件

经济安全、成熟专业能力、稳定原创交付、长期读者关系、可持续商业经营、生活与职业韧性。

每季度依据证据判断各条件的状态：未建立、萌芽、稳定、可扩展，允许退步。数据不足时明确显示无法判断。（状态评估在 V2 实现。）

## 三种十年情景

这是推演工具，不是预测，不给出成功概率。

- **乐观**：持续成长，形成独立作品，获得重要合作机会，建立成熟商业体系和较大选择自由。
- **基准**：形成稳定收入、适度读者规模、成熟专业能力和长期作品积累。
- **悲观**：受不利环境影响，同时长期无法改善现金流和个人作品的持续交付。

重点不是猜哪种情景会发生，而是检查自己是否正在建立通往理想生活的必要条件。

## 当前阶段：经济安全和长期创作基础建设期（2026年10月 至 2027年）

默认排序：

1. 维护现实生活和必要的经济安全
2. 推进已有职业合作，提高收入稳定性
3. 建立每周持续发表个人作品的机制
4. 维持健康、必要保障和重要关系
5. 深化专业研究、AI 协作及长期能力

这不是要求忽视排在后面的领域，健康、休息和必要关系维护始终保留基本空间。经济状况改变后可以调整资源分配。

## 寻找主要限制因素

每季度回答三个问题：

1. 当前最制约发展的一个因素是什么？
2. 如果先改善它，可能释放哪些其他机会？
3. 为什么它比其他问题更重要？

例如：现金流不足时，经济安全可能是主要限制；经济安全改善但原创长期停滞时，持续创作机制可能成为主要限制；作品稳定但缺少读者关系时，重点可能转向传播和商业验证。不能机械地维持同一套优先级十年。

## 行为假设放在哪里

用户对自己行为模式的推测（例如在什么条件下更容易行动），属于待验证假设，不属于事实。它们应写进应用的「事实、假设与约束」，类型选「待验证假设」，可以随新证据标记为不再成立。
